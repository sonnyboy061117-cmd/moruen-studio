使用教程

5 分钟掌握墨韵工坊的全部能力，从 0 到 1 搭建你的内容生产流水线

1

配置你的 API 密钥

进入「模型秘钥」，填入至少一个模型提供商的 API Key。所有密钥本地加密存储，不上传服务器。

2

用「一键标题」生成爆款标题

粘贴 1-5 个参考标题，选择领域和风格，AI 举一反三生成 1-20 条候选标题。

3

用「批量原创」一鱼多吃

把满意的标题导入「批量原创」，设置每主题 3-5 篇、字数 800-1500 字，120 篇并发跑完。

4

不满意？用「批量改写」换角度重写

直接粘贴爆款链接，AI 抓取原文后多角度改写。也可以用「万能改写」处理自己已有的文章。

5

用「一键排版」直接生成公众号格式

5 套风格随心选，AI 自动配图、行间距字号都可调。一键复制粘贴到公众号编辑器。

6

担心 AI 痕迹？用「降 AI 味」四阶段处理

去模板 → 增口语 → 调句式 → 加温度。朱雀 AI 检测平台验证，部分领域人工特征占比可达 100%。

7

一条龙工作流：标题 → 原创 → 改写 → 排版 → 降 AI → 配图 → 发布

所有功能在右侧边栏一键切换，每一步结果可以无缝导入下一步，5 分钟搞定一周内容。
